# Twillory Ad Creation

Private working repository for Twillory creative strategy and production, led by Brandon Wasoski.

## Start here

- [WORKFLOW.md](WORKFLOW.md): stage-by-stage runbook from Conversation Scan through launch and learning.

- [PROCESS.md](PROCESS.md): complete workflow, canonical skill references, fresh-research rules and Monday verification/recovery.

- [AGENTS.md](AGENTS.md): operating rules and production handoffs.
- [PROJECT_STATUS.md](PROJECT_STATUS.md): completed work, outstanding work, and weekly targets.

Start with WORKFLOW.md and read the relevant references before starting work. Check current testing-plan files and Monday tasks before making concept-level claims or creating production tasks.

## Purpose

Keep process instructions and project progress available across sessions. A testing plan, a finished brief, a Monday task, and a finished creative are separate milestones.

## Repository phase

Client-specific process documentation and status baseline. PROCESS.md references existing canonical Growthub skills without duplicating them. No new personal skill has been installed. The existing testing-plan files, Google Docs, dashboard, and workflow images have not been copied into the repository.
